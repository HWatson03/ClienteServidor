ClienteServidor - Web

Requisitos:
- Navegador moderno
- Conexión al servidor backend con HTTPS

Configuración:
- Requiere login (sin acceso anónimo)
- Sin biometría
- Sin subida en segundo plano al cerrar pestaña

Compilación:
flutter build web --release

Despliegue:
Subir build/web/ al servidor web
